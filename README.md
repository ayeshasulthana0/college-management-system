
# College Management System

## Project Description
College Management System is a backend application developed using Java and Spring Boot. It manages students, faculty, courses and attendance through REST APIs.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- REST API
- Postman
- Maven

## Modules
- Student Management
- Faculty Management
- Course Management
- Attendance Management

## API Endpoints

### Students
- GET /api/students
- POST /api/students
- PUT /api/students/{id}
- DELETE /api/students/{id}

### Faculty
- GET /api/faculty
- POST /api/faculty
- PUT /api/faculty/{id}
- DELETE /api/faculty/{id}

### Courses
- GET /api/courses
- POST /api/courses
- PUT /api/courses/{id}
- DELETE /api/courses/{id}

### Attendance
- GET /api/attendance
- POST /api/attendance
- PUT /api/attendance/{id}
- DELETE /api/attendance/{id}

## Database
MySQL database: college_management

## Testing
All REST API endpoints are tested using Postman.
